# Практическое задание: диспетчер уведомлений

Необходимо реализовать диспетчер уведомлений, поддерживающий отправку сообщений по каналам **email** и **push**.

## Требования

1. Описать интерфейс `Notifier` с методом `Send`.
2. Создать две реализации интерфейса:
   - отправка по email;
   - отправка push-уведомлений.
3. Реализовать диспетчер, принимающий срез `[]Notifier`.
4. Проверить корректность вызовов с помощью тестов.
