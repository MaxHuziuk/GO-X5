# Практическое задание: обработка ошибок и паник

Необходимо реализовать примеры обработки паник и кастомных ошибок в Go.

## Требования

1. Создать несколько вложенных функций.
2. Вызвать `panic` на нижнем уровне вложенности.
3. Попробовать перехватить панику с помощью `defer` и `recover` на разных уровнях.
4. Проверить, как меняется выполнение программы в зависимости от места вызова `recover`.
5. Создать собственный тип ошибки.
6. Реализовать для кастомной ошибки метод `Error`.
7. Реализовать метод `Unwrap` для получения вложенной ошибки.
8. Реализовать метод `Is` для сравнения ошибок.
9. Проверить работу кастомной ошибки с помощью:
   - `errors.Is`;
   - `errors.As`;
   - `errors.Unwrap`.
10. Добавить тесты для обработки паник и кастомной ошибки.
